Secure Docker Sandbox

Every program submitted by students is executed inside an isolated Docker container. This ensures complete security, prevents malicious code execution, and provides a consistent runtime environment for all users.

  • Isolated Code Execution
  • CPU & Memory Limits
  • Execution Time Limits
  • Network Access Disabled
  • Automatic Container Cleanup
