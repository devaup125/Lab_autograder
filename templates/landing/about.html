About The Project

Lab Auto Grader is an intelligent web-based platform developed to automate programming laboratory evaluation. It helps teachers create coding assignments, securely execute code using Docker, evaluate student submissions against hidden test cases, generate leaderboards, and provide instant feedback. The platform reduces manual effort, improves evaluation accuracy, and provides students with a coding experience similar to LeetCode and HackerRank.
